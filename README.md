# ระบบสอบแพทย์

ซอร์ส Google Apps Script สำหรับระบบสอบแพทย์ตามชั้นยศ ใช้ Google Sheets เป็นฐานข้อมูลหลังบ้าน

## ไฟล์

- `Code.gs` — Apps Script backend และการเชื่อมต่อ Google Sheets/Drive/Discord
- `Index.html` — หน้าเว็บทั้งหมด (ใน Apps Script ต้องตั้งชื่อไฟล์ HTML ว่า `Index`)
- `index.html` — ทางเข้า Cloudflare Pages ซึ่ง redirect ไปยัง Apps Script Web app

## ความสามารถ

- **สมัครแพทย์** — ผู้สมัครเก็บในชีต `Applicants` แยกจากบุคลากร (`Users`) และทำข้อสอบเข้าแพทย์ได้ทันทีหลังสมัคร
  ADMIN กด "รับเข้าเป็นบุคลากร" เพื่อเพิ่มเข้าชีต `Users` พร้อมรหัสพนักงานและยศ
- **ข้อสอบ** — ข้อช้อย/ข้อเขียน สุ่มจากคลังของชุดตามยศ สลับลำดับตัวเลือกต่อผู้สอบ แนบรูปได้ จับเวลาตามชุด
- **ตรวจและแจ้งผล** — ตรวจข้อเขียนด้วยคีย์เวิร์ด + ผู้บริหารยืนยัน, คะแนนย้อนหลัง, รายงานตามช่วงวันที่, ประกาศผลเข้า Discord ตามชุดข้อสอบ
- **นำเข้าข้อสอบจาก Excel** แบบ batch
- **สิทธิ์ 3 ระดับ** — SUPER (ผู้พัฒนา) / ADMIN / ทั่วไป · ทุกการกระทำบันทึกในชีต `AuditLog`
  - ADMIN: จัดการผู้ใช้ สร้าง/รีเซ็ตรหัสผ่าน จัดการสิทธิ์ ตั้งค่าชุดข้อสอบ จัดการข้อสอบ ตรวจข้อเขียน รับผู้สมัคร (ยกเว้นบัญชีผู้พัฒนา)
  - SUPER: ทุกอย่าง + ตั้งค่า Discord Webhook และจัดการบัญชีผู้พัฒนา

## การเข้าสู่ระบบ

| ระดับ | เข้าสู่ระบบด้วย |
|---|---|
| ADMIN / SUPER (ผู้พัฒนา) | **รหัสผ่านของตัวเอง** (6–10 ตัว มีตัวเลข a–z A–Z และอักขระพิเศษ) · เปลี่ยนเองได้ที่ปุ่ม "เปลี่ยนรหัสผ่าน" |
| ยศอื่นทั้งหมด | **รหัสผ่านครั้งเดียว** ที่ ADMIN / SUPER สร้างให้ในหน้า "จัดการผู้ใช้ & รหัสผ่าน" |

รหัสผ่านครั้งเดียว:
- รหัส 8 ตัว (เช่น `ABCD-2345`) ใช้เข้าสู่ระบบได้ **1 ครั้ง** และหมดอายุตามเวลาที่เลือก (1 ชม. – 3 วัน)
- สร้างรหัสใหม่แล้วรหัสเดิมที่ยังไม่ได้ใช้จะใช้ไม่ได้ทันที
- สำหรับ ADMIN / SUPER ใช้เป็น**รหัสชั่วคราว** ตอนเข้าครั้งแรกหรือลืมรหัส (ปุ่ม "รีเซ็ตรหัสผ่าน") — เข้าด้วยรหัสนี้แล้วระบบบังคับตั้งรหัสผ่านของตัวเอง และรหัสเดิมจะใช้ไม่ได้
- เก็บเฉพาะ hash ในชีต `Users` (`PasswordHash` = รหัสของผู้บริหาร, `OtpHash` / `OtpExpires` = รหัสครั้งเดียว)
- ผู้พัฒนาคนแรก / กู้คืนบัญชีผู้พัฒนา: เปิดไฟล์ Google Sheet → เมนู **ระบบสอบ → สร้างรหัสผ่านครั้งเดียวให้ DEV001**
  (ใช้ได้เฉพาะจากเมนูในชีต เรียกจากหน้าเว็บไม่ได้)

## ติดตั้ง Apps Script

1. เปิดโปรเจกต์ Google Apps Script ที่ผูกกับ Google Sheet ของระบบ (ส่วนขยาย → Apps Script)
2. คัดลอก `Code.gs` และ `Index.html` เข้าโปรเจกต์ โดยตั้งชื่อ HTML file ว่า `Index`
3. รัน `setup()` จาก Apps Script Editor และอนุญาตสิทธิ์ Google Sheets/Drive ตามที่ระบบร้องขอ
   (ถ้าใช้ Discord Webhook ให้รัน `authorizeUrlFetch()` หนึ่งครั้งด้วย)
4. Deploy เป็น Web app และกำหนดสิทธิ์เข้าถึงให้เหมาะกับองค์กร
5. รีเฟรชไฟล์ Google Sheet → เมนู **ระบบสอบ → สร้างรหัสผ่านครั้งเดียวให้ DEV001** แล้วใช้รหัสนั้นเข้าเว็บและตั้งรหัสผ่านของตัวเอง

อัปเดตโค้ด: วางทับ → รัน `setup()` (ไม่ทับข้อมูลเดิม และย้าย/ปรับข้อมูลเก่าให้อัตโนมัติ) → Deploy → จัดการการทำให้ใช้งานได้ → เวอร์ชันใหม่

## Cloudflare Pages

Pages entry file `index.html` redirects visitors to the current Apps Script Web app URL. The app itself stays on Apps Script so `google.script.run`, Google Sheets and the existing login continue to work. Deploy the `cloudflare` folder as the Pages output directory, or use the repository root after copying its `index.html` there.

## ชีตหลังบ้าน

`Users` · `Applicants` · `Exams` · `Questions` · `Results` · `Answers` · `Permissions` · `AuditLog`

ระบบลงเวลาเข้า–ออกเวรถูกนำออกแล้ว — ชีต `Attendance`, `PayrollConfig`, `PayrollRates` และโฟลเดอร์ Drive "หลักฐานลงเวลา" ของเดิม (ถ้ามี) ระบบไม่ลบให้ ลบเองได้ถ้าไม่ใช้

## การตั้งค่าและข้อมูลลับ

- ห้ามเก็บรหัสผ่าน, Discord Bot Token, Webhook URL หรือข้อมูลผู้ใช้จริงในซอร์สโค้ด
- Webhook และค่าภายในเก็บใน Script Properties; ข้อมูลผู้ใช้/ผู้สมัครอยู่ใน Google Sheet ที่จำกัดสิทธิ์
- GitHub repository นี้เป็น public ตามที่เจ้าของระบบเลือก อย่าใส่ข้อมูลจากชีตจริงหรือ secret ลงในไฟล์ที่ commit
